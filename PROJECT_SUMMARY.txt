DocuShop - Document Composition Platform
=========================================

PROJECT OVERVIEW
----------------
A HIPAA-compliant document composition platform for clinical use that enables
authorized staff to create, brand, autofill, sign, audit, and export official
documents (doctor's excuses, verification letters, visit summaries, reports).

GETTING STARTED
---------------
1. Clone repository
2. Backend: cd backend && python -m venv venv && pip install -r requirements.txt
3. Frontend: cd frontend && npm install
4. Start MongoDB: docker run -d -p 27017:27017 mongo:7
5. Seed database: python backend/seed.py
6. Run backend: uvicorn app.main:app --reload
7. Run frontend: npm run dev

Or use Docker Compose:
  docker-compose up --build
